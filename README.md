# Lanzarote 2026

Авторский travel-magazine лендинг для путешествия на Lanzarote 3–9 ноября 2026.

## Стек

- React
- Vite
- Framer Motion
- Lucide icons

## Запуск

```bash
npm install
npm run dev
```

## Медиа

Положите три исходных постера в `public/images/` с именами:

- `lanzarote-cover.png`
- `timanfaya.png`
- `la-graciosa.png`

Дальше можно расширять серию новыми обложками для Manrique, La Geria, Jameos del Agua, Famara и El Golfo.
